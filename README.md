# Практикум к лекции № 10: выбор места для офиса по геоданным

Учебный стенд с FastAPI, Swagger UI и картой Чебоксар. Студент получает
персональный токен, загружает CSV сотрудников и GeoJSON офисов, строит зоны
доступности и отправляет выбранные офисы на автоматическую проверку.

Имена сотрудников вымышлены. Координаты домов и офисов используются только как
учебный набор данных.

## Локальный запуск

Нужен Python 3.11 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8011
```

Откройте <http://127.0.0.1:8011/>. Страница показывает карту и Swagger UI.
Регистрация выдаёт персональный Bearer-токен; база SQLite по умолчанию
создаётся в `.local/office-pilot.sqlite3`.

## Маршрут работы

1. `GET /employees.csv` загружает сотрудников.
2. `GET /offices.geojson` загружает офисы.
3. Восемь запросов `POST /isochrones` строят зоны доступности и обновляют
   их общее пересечение на карте.
4. `POST /decision` проверяет выбор офисов.
5. `POST /submit` записывает результат и сообщает статус Telegram-уведомления.

## Настройки

Для уведомлений преподавателю задайте на сервере переменные среды
`DELIVERY_LAB_TELEGRAM_TOKEN` и `DELIVERY_LAB_TELEGRAM_CHAT_ID`. Значения
секретов не хранятся в репозитории. При отсутствии настроек результат сдачи
всё равно сохраняется, а уведомление остаётся в очереди. Повторная отправка
выполняется командой `python3 retry_telegram.py`.

Путь к базе данных можно переопределить переменной `OFFICE_PILOT_DATABASE`.
Пример systemd unit находится в `deploy/office-location-lab10.service`.

Не добавляйте в Git `.env`, локальную базу данных, файлы из `.local/`,
виртуальное окружение или данные реальных студентов.

## Файлы данных и исходники

- `employees.csv`, `employees.geojson` — восемь условных сотрудников.
- `offices.geojson` — пять возможных офисов.
- `zones.geojson`, `common-zone.geojson` — учебные зоны доступности и их
  пересечение для предварительного просмотра.
- `app.py`, `workbench.html` — API, карта и интерфейс Swagger.
- `build.py` — построение геоданных на основе OpenStreetMap.
- `export_teacher_csv.py` — выгрузка журнала преподавателя из локальной базы.
- `retry_telegram.py` — повторная отправка ожидающих уведомлений.
- `preview.html` — автономная визуализация набора данных.

Геоданные основаны на [OpenStreetMap](https://www.openstreetmap.org/copyright)
и [OSMnx](https://osmnx.readthedocs.io/en/stable/). Фоновая карта загружается
из [OpenFreeMap](https://openfreemap.org/) и требует интернет-соединения.
